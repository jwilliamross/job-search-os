# Prompt showcase

Some postings now say "if you used an LLM, include your prompts." Some employers are
AI-curious and the workflow is a selling point. Others are not. This skill makes the
artifact and makes the go/no-go call.

## Decide first

Attach it when: the posting asks for it (mandatory); the posting mentions AI, automation,
or data; the firm is small, technical, or founder-led; the role is in strategy, corp dev,
or consulting where tool fluency sells. Do not attach it when the posting forbids AI
assistance or asks for a handwritten-style personal statement, or when the firm is
traditional and the posting says nothing about tools. Record the decision in `notes.md`.

## What the appendix contains (150-300 words, page 2 of the letter)

1. **What the system is, in the user's words.** The repo, the fact sheet every claim must
   trace to, the hand-written voice samples, the skills for each step.
2. **What the research step did for this posting.** Which pages it fetched, that it built a
   requirements-versus-evidence table, and that it chose what to reference from that table.
3. **That the user edited by hand.** Honest and short.
4. **The core prompt**, cleaned of private facts, in quotation marks so the renderer boxes it.
5. **A link** to the public repo the user controls, never to a private one.

## Safety check before publishing

Grep the appendix for phone numbers, addresses, family names, client names, financial
details, and anything that looks like a key or token. Remove anything found.
